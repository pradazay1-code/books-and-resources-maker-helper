# Embedded fonts

All three families are licensed under the **SIL Open Font License 1.1**, which permits
embedding in documents including commercial ones. They are committed here so the build
is reproducible without network access.

| Family | Role | Designer / source |
|---|---|---|
| **Source Serif 4** | Body text, 11/16 pt | Frank Grießhammer, Adobe — OFL 1.1 |
| **Archivo** | Headings, running heads, UI furniture | Omnibus-Type — OFL 1.1 |
| **JetBrains Mono** | Script and template boxes | JetBrains — OFL 1.1 |

Under the OFL, embedding these in the PDF is permitted and no attribution is required in
the book itself. This file records provenance for the repository.

If the OneVision wordmark's real typeface is licensed differently, it must be converted to
outlines rather than embedded — see `build/assets/BRAND-ASSETS-NEEDED.md`.
