**Chapter 7 · Stage 3 — Volume**

Six stages. Not twelve. A pipeline you maintain beats a pipeline you abandon.

### The stages

| Stage | Means | Moves forward when |
|---|---|---|
| **Cold** | On the list, never contacted | First touch sent |
| **Touched** | Contacted, no response | Any reply, or sequence exhausted |
| **Replied** | Responded, including "not interested" | A real back-and-forth |
| **Conversation** | Engaged past the first exchange | Call scheduled |
| **Call Booked** | Time on the calendar | Call happens |
| **Proposal Out** | They've heard the price | Signature or a no |

### Fields per record

Name · Owner name · Phone · Email · **One specific detail** · Source · Touch count · Last touch date · Next touch date

That "one specific detail" field is what makes your first line not sound like a blast. It's the most important column.

### The outreach day

**Before the block** (once a week, separate session)
- [ ] Add 100+ businesses to Cold
- [ ] Each row: name, owner, phone, email, one specific detail

**The block** (same time daily)
- [ ] Work **Touched** first — every follow-up due today
- [ ] Work **Cold** — new contacts until the number is hit
- [ ] Move anyone who replied into Replied
- [ ] Log: attempts ___ replies ___ convos ___
- [ ] Close it. Don't reopen at 11pm.

**Weekly** (4 minutes, Sunday)
- [ ] Total the three columns
- [ ] Count what's sitting in each stage
- [ ] Name the single biggest drop-off — that's next week's problem

### Reading the drop-offs

| Where it piles up | What it means |
|---|---|
| Cold → Touched | You're not hitting your number |
| Touched → Replied | Message or targeting |
| Replied → Conversation | Opener is interesting, offer isn't landing |
| Conversation → Call Booked | You're not asking for the call directly |
| Call Booked → Proposal | Show rate, or the call structure |
| Proposal → Signed | Price, or the objection you're not handling |
