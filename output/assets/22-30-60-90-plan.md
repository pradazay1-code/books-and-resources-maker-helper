# 30/60/90 Execution Plan
> **From The OneVision Playbook** by Isaiah Wright · onevision asset vault

The whole book as a calendar. If you do nothing else, do this in this order.

## Days 1–30 · Get to your first conversation

The goal of month one is not a client. It's a working outreach habit and a real pipeline.

- [ ] Write your attempt-number commitment and the date *(Ch. 1)*
- [ ] Find your daily block and set the recurring calendar event *(Ch. 2)*
- [ ] Score three verticals, pick one, draw the radius *(Ch. 3)*
- [ ] Count the qualifying businesses inside it *(Ch. 3)*
- [ ] Fill the offer builder; say the one-sentence version out loud ten times *(Ch. 4)*
- [ ] Do the job-value arithmetic for one real business *(Ch. 5)*
- [ ] Set your setup fee and monthly *(Ch. 5)*
- [ ] Book the attorney review of your MSA and SOW *(Ch. 6)*
- [ ] Build the six-stage outreach pipeline *(Ch. 7)*
- [ ] Add 200+ businesses to Cold *(Ch. 7)*
- [ ] Write your four-part message for two channels *(Ch. 8)*
- [ ] Start your own A2P 10DLC brand registration *(Ch. 11)*
- [ ] **Hit your daily number every single day**

## Days 31–60 · Get to your first client

Month two is conversations. Outreach is running; now the skill is on the call.

- [ ] Write and rehearse your opening frame *(Ch. 9)*
- [ ] Build your fifteen-question discovery sheet *(Ch. 9)*
- [ ] Write your answer to all twelve objections; say each out loud *(Ch. 10)*
- [ ] Run calls. Tally which objections actually appear *(Ch. 10)*
- [ ] Review stage-to-stage conversion weekly; fix the biggest drop-off *(Ch. 7)*
- [ ] Build the client-side pipeline and speed-to-lead automation *(Ch. 12)*
- [ ] Test the whole path as a fake lead from your own phone *(Ch. 12)*
- [ ] Write your day 0–14 onboarding checklist *(Ch. 13)*
- [ ] Audit every document for income claims *(Ch. 6, 17)*
- [ ] **Keep hitting your daily number, including on call days**

## Days 61–90 · Deliver, prove, tip the next one

Month three is where the domino either starts or doesn't. It starts with delivery.

- [ ] Submit client A2P registration within one business day of signature *(Ch. 11)*
- [ ] Send a progress note every 2–3 days during the registration wait *(Ch. 13)*
- [ ] Get real calendar availability in writing *(Ch. 13)*
- [ ] Build the reminder stack *(Ch. 13)*
- [ ] Call the client the day the first appointment books *(Ch. 13)*
- [ ] Build the one-page report and send it on time *(Ch. 14)*
- [ ] Set the two-week check-in as a recurring task *(Ch. 15)*
- [ ] Ask for a referral the day a job is reported won *(Ch. 16)*
- [ ] Get written permission before using any result publicly *(Ch. 16, 17)*
- [ ] Snapshot the build so the next one takes hours *(Ch. 12)*
- [ ] Start your mistake list *(Ch. 18)*
- [ ] **Still hitting the daily number**
